# 🧪 sandbox

A graveyard of half-baked ideas and learning experiments.

This repo is a dumping ground for non-functional projects built for learning purposes — rough code, dead ends, and works-in-progress that exist purely to explore concepts.

## What's here

- Experiments with new languages, frameworks, or tools
- Tutorials and courses followed along
- Proof-of-concepts that never made it further
- Code written to understand how something works

## Rules

- Nothing here is production-ready
- Nothing here is meant to be maintained
- Everything here taught me something
